# HS-1

**HS-1 Kinematic Suit** is a full-body motion tracking system based on multiple ESP32-C3 nodes and BNO055 IMU sensors.

The project is designed to capture real-time body movement and orientation data, with support for sensor communication, data processing, and 3D visualization.

## Features

* Full-body motion tracking
* Multiple BNO055 IMU sensors
* ESP32-C3 sensor nodes
* I2C and UART communication
* Real-time motion data
* 3D model visualization
* Fusion 360 hardware design

## Technologies

* C++
* Python
* ESP32-C3
* BNO055
* I2C / UART
* PlatformIO
* Fusion 360
